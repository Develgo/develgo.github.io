## Apple Platforms and User Interfaces

Apple offers a wide variety of device form factors and operating systems. On the desktop you have [macOS](https://developer.apple.com/macos/). User interfaces for the Mac are built with a framework called [AppKit](https://developer.apple.com/documentation/appkit), however, the preferred framework is now SwiftUI.

On the mobile side you have [iOS](https://developer.apple.com/ios/) for phones, and [iPadOS](https://developer.apple.com/ipados/) for tablets. Both of these use a framework called [UIKit](https://developer.apple.com/documentation/uikit) for building user interfaces, however, the preferred framework is now SwiftUI.

Other devices include the AppleTV that runs [tvOS](https://developer.apple.com/tvos/), a virtual and augmented reality device called the Vision Pro that runs [visionOS](https://developer.apple.com/visionos/), and the Apple Watch that runs [watchOS](https://developer.apple.com/watchos/). You can use SwiftUI to build user interfaces for all of these devices.

To build applications for Apple Platforms the preferred IDE is [Xcode](https://developer.apple.com/documentation/xcode) that can be downloaded on the Mac AppStore.
