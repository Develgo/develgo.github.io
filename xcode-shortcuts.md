# Xcode Keyboard Shortcuts

## General

| General                         | Shortcut |
| ------------------------------- | -------- |
| Settings                        | ⌘,       |
| Documentation                   | ⇧⌘0      |
| Documentation for selected text | ⌃ ⌘?     |
| Quick help                      | ⌘?       |

| ----------------- | -------- |

| Next completion   | ⌃.       |
| Accept completion | Tab      |
| Next placeholder  | ⌃/       |
